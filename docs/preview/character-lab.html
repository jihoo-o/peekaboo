이 프리뷰가 보여주는 것

다섯 모델은 모두 같은 파츠 정의(구·캡슐·원기둥 12개)를 스타일별로 다르게 렌더한 결과입니다. 이미지 파일 없이 three.js 코드만으로 만들었으므로, 고른 스타일은 Peekaboo에도 파일 추가 없이 그대로 들어갑니다.

다음 단계

  1. 스타일 하나를 고른다 (두 개를 섞는 것도 가능. 예: 셀 툰 외곽선 + 클레이 질감).
  2. 몸 색 6종을 별사탕 수집 정체성에 연결한다. 위 색 칩이 그 6색이다.
  3. app.js의 drawCharacter()를 오프스크린 three.js 렌더로 교체하고, 마스크 오클루전은 그대로 둔다.
  4. 헤드리스 가짜 카메라로 등장·수집 화면을 검증한 뒤 폰에서 fps를 확인한다.

저작권 메모

춘식이는 카카오의 IP입니다. 여기 모델은 형태를 새로 만든 오마주라 개인 프로젝트에는 문제없지만, 스토어에 올리려면 귀 모양·얼굴 배치·받침 같은 식별 요소를 더 바꿔 원작과 구분되게 해야 합니다.

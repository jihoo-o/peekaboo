Fluent 이모지 모션 시트

Fluent 3D 이모지 움직이는 이모티콘 시트

59종 중 45종은 Microsoft가 MIT로 공개한 공식 애니메이션(APNG)이 있어서 그대로 돌리고, 나머지 14종은 정지 이미지에 이모티콘 모션을 입혔습니다. 위 버튼으로 모션을 바꾸면 59칸 전부에 적용되고, 칸을 탭하면 찌그러졌다 튕깁니다. 공식 애니메이션은 128px 애니 WebP로 줄여 넣었습니다.

모션
탭 = 찌그러짐 · 노란 테두리 = Peekaboo 후보

여기서 쓴 이모티콘 모션 문법 9가지

카카오 움직이는 이모티콘의 관행(짧은 루프, 동작 1개 + 강조 이펙트 1개, 시작과 끝 포즈 같게)을 CSS 키프레임으로 옮긴 것입니다. Peekaboo 상태와의 매핑을 함께 적었습니다.

Peekaboo에 넣을 때

  • 충전(5초): 덜덜. 짠! 등장: 짠!. 대기: 공식 애니메이션 또는 통통. 탭: 찌그러짐. 수집: 눈물 → 반짝.
  • 앱은 2D 캔버스라 CSS 대신 drawImage에 같은 변환(translate·scale·rotate)을 적용하면 됩니다. 공식 APNG는 캔버스에 그리면 첫 프레임만 나오므로, 캔버스 위에 <img>를 겹치거나 WebP 프레임을 직접 넘겨야 합니다.
  • 마스크 오클루전은 캐릭터 요소 위에 비디오를 덮는 방식이라 <img>를 쓰면 마스크 캔버스를 그 위 레이어로 올려야 합니다.

파일과 라이선스

  • 공식 애니메이션 원본: microsoft/fluentui-emoji-animated (MIT, 256px APNG, Git LFS 약 5GB). 여기서는 Tarikul-Islam-Anik 미러에서 받아 128px·절반 프레임 애니 WebP로 변환했습니다(45종 5.7MB).
  • 정지 3D PNG: microsoft/fluentui-emoji (MIT).
  • MIT 조건은 저작권 고지 포함뿐입니다. 저장소에 LICENSE 사본을 함께 두었습니다.

한계

  • 녹는 얼굴은 공식 애니메이션이 없습니다(14종 정지). 공식 애니메이션 프레임 수와 길이는 캡션에 적었습니다.
  • 눈물·터짐선 같은 이펙트 위치는 칸 기준 고정이라 이모지마다 눈 위치와 조금 어긋납니다. 채택되면 캐릭터별로 좌표를 맞춥니다.
  • 공식 애니메이션은 멈출 수 없습니다. 시스템의 "동작 줄이기" 설정에서는 우리 모션만 꺼집니다.

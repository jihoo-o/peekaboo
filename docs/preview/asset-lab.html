새로 그리지 않고 가져다 쓸 수 있는 캐릭터 에셋을 라이선스 기준으로 모았습니다. 순수 MIT는 Microsoft Fluent Emoji 하나가 사실상 전부이고, 3D 모델(GLB) 쪽은 CC0(저작권 포기)가 MIT와 같은 역할을 합니다. 아래 갤러리의 이미지는 실제 MIT 파일을 그대로 가져온 것입니다.

지금 당장: Fluent Emoji 3D (MIT)

Microsoft가 MIT로 공개한 3D 스타일 PNG. 유령·물범·병아리·감자·햄스터·식빵이 전부 있고, 지금 앱이 2D 캔버스라 PNG 한 장이면 오늘 교체됩니다. 표기 의무 없음, 상업 사용 가능.

진짜 3D가 필요하면: CC0 GLB 팩

Gobkit(물범·오리·마못, 리깅+애니메이션), KayKit Halloween Bits(유령), Quaternius(동물·귀여운 몬스터), Kenney. 전부 CC0라 표기 없이 상업 사용 가능.

한국 감성 2D: 토스페이스 (자체 라이선스)

토스가 만든 이모지 폰트. 폰트로는 무료·상업 사용 가능하지만 판매 금지이고, 3D 토스페이스 이미지는 개인·상업 모두 사용 불가입니다.

Fluent Emoji 3D 후보 59종

노란 테두리가 Peekaboo 베이스 후보입니다. 앞서 제안한 5안(두더지·물범·식빵·병아리·유령) 중 두더지만 없어서 햄스터·다람쥐가 대체입니다. 얼굴 이모지는 표정 파츠 참고용입니다.

3D 모델(GLB)이 필요할 때: CC0 캐릭터 팩

Peekaboo에 넣는 방법 3가지

  1. PNG 스프라이트(가장 빠름): Fluent 3D PNG를 assets/에 두고 drawCharacter()에서 drawImage. 튀어나오기·찌그러짐은 캔버스 변환으로. 표정은 눈·볼·눈물 파츠를 그 위에 2D로 덧그림.
  2. GLB 3D: Gobkit 물범이나 KayKit 유령을 GLTFLoader로 불러 오프스크린 렌더. 애니메이션 클립이 있으면 상태(peek·idle·wave)에 매핑.
  3. 합성: Fluent 3D PNG 몸 + 앞서 만든 표정 파츠. 몸은 MIT 에셋, 표정만 우리 것.

라이선스 실무 메모

  • MIT는 "저작권 고지와 허가 문구를 포함"만 하면 됩니다. 저장소에 LICENSE 사본을 함께 두면 충족됩니다.
  • CC0는 고지 의무도 없습니다. 그래도 README에 출처를 적어 두는 게 관례입니다.
  • CC BY는 앱 정보 화면이나 README에 제작자·라이선스·링크를 적어야 합니다.
  • CC BY-SA는 수정본까지 같은 라이선스로 공개해야 하므로 상용 앱에는 부담됩니다.

이 도감의 한계

  • kenney.nl, quaternius.com, gobkit.com, poly.pizza, itch.io는 이 환경에서 직접 열리지 않아 검색 요약과 알려진 라이선스로 표기했습니다. 다운로드 시 재확인 필요.
  • Noto 3D 이모지 공개는 블로그 한 곳의 주장만 확인됐고 저장소에서 3D 폴더를 찾지 못했습니다.
  • Fluent 3D는 PNG라서 카메라 각도를 바꾸는 진짜 3D 연출은 안 됩니다. 필요하면 GLB 경로로 갑니다.

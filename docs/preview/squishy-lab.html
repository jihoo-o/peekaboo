하찮음 슬라이더가 바꾸는 것

  • 몸: 위아래로 눌리고 옆으로 퍼짐. 바닥이 처짐.
  • 눈: 작아지고, 멀어지고, 얼굴 아래쪽으로 내려감. 오른눈이 살짝 높음.
  • 입·코·주둥이: 작아짐. 볼 터치는 커지고 내려감.
  • 팔: 만세에서 뭉툭한 돌기로. 귀는 작아짐.

말랑함 슬라이더가 바꾸는 것

  • 찌를 때 찌그러지는 깊이와 출렁이는 시간(스프링 감쇠).
  • 가만히 있을 때의 숨쉬기 폭.
  • Peekaboo에서는 탭 반응(wave)과 등장(peek)의 스쿼시 세기로 쓰입니다.

저작권 메모

원본 스티커는 카카오 IP입니다. 하찮음 60 이상이면 눈·팔·비율이 원작과 꽤 달라지지만, 스토어 배포 전엔 귀와 받침 모양도 바꾸는 편이 안전합니다.

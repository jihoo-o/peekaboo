# ADR-0012: 수집 게임 — 캐릭터 정체성은 별사탕 색 6종, 등장마다 무작위

- 날짜: 2026-09-15 · 상태: 채택

## 맥락
요청: 탭 → 수집(게임 포맷), 수집된 캐릭터와 스타일 구분, 이미 수집된 건 다시 탭해도 모션만. 캐릭터 디자인은 첨부 이미지(검댕이 + 색색 별사탕). "무엇을 수집하는가"의 단위를 정해야 했다.

## 결정
- 수집 단위 = **별사탕 색 6종**(`SPRITES`). 캐릭터가 등장할 때마다 하나를 고르되, 미수집이 남아 있으면 70% 확률로 미수집 중에서 고른다.
- 미수집: 별사탕 없음, 살짝 옅게(alpha 0.86), 머리 위 노란 "!" 말풍선. 탭 → `collect` 연출(점프 + 별사탕 등장 + 반짝) → 도감에 저장.
- 수집됨: 별사탕을 들고 있음, 불투명. 탭 → `wave`(흔들기 + 점프)만.
- 도감은 `localStorage['peekaboo.collection']`, 우상단 배지(★ n/6) 탭 → 패널. 패널 썸네일은 같은 `drawCharacter`로 그린다.
- 등장 조건(S7): 타깃 확정 후 **5초 유지** 동안 "충전" 연출(물체 위로 떠오르는 검댕 알갱이 + 진행 호), 그 뒤 1.6초에 걸쳐 천천히 peek.

## 이유 (공수)
- 색 6종은 이미지 에셋 없이 `fillStyle` 하나로 구분된다. 캐릭터 종류를 늘리려면 `SPRITES` 배열에 한 줄.
- 물체 클래스별 캐릭터(컵→A, 병→B)는 ADR-0011로 클래스가 하나로 고정돼 수집 게임이 성립하지 않는다.
- 검댕이 디자인은 원·선·타원만으로 그려져 첨부 이미지의 요소(검은 털뭉치, 큰 흰 눈, 별사탕)를 그대로 재현하면서 기존 `drawCharacter` 시그니처를 유지한다.

## 결과
- 헤드리스 검증: 확정 → charging → peek → idle, 탭 1회 → `collect`(도감 1/6, localStorage 저장), 탭 2회 → `wave`.
- 실기기에서 5초 유지가 너무 길면 `HOLD_MS`, 등장 확률 편향은 `pickSprite`의 0.7을 조정.

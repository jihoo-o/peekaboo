# ADR-0006: 마스크 IoU 게이트·EMA를 메인 스레드 픽셀 루프로, 워커 없음

- 날짜: 2026-09-15 · 상태: 채택

## 맥락
S4에서 (a) 마스크-bbox IoU 계산, (b) 픽셀별 EMA, (c) 알파 채널 굽기(`putImageData`)를 어디서 할지. 비디오 해상도(720p면 92만 픽셀)를 10Hz로 세 번 순회한다.

## 결정
세그 콜백 안에서 메인 스레드 `for` 루프로 처리한다. 다운샘플·Web Worker·OffscreenCanvas는 쓰지 않는다.

## 이유 (공수)
- 워커는 MediaPipe 호환 확인이 먼저 필요하고(계획 §4에서도 "스파이크 후 결정"), 마스크 전송·복사 코드가 추가된다.
- 10Hz × 100만 픽셀 단순 루프는 폰에서도 수 ms대로 예상. 문제가 되면 `?res=480`으로 4배 줄이는 손잡이가 이미 있다.

## 결과
실기기에서 세그 Hz 또는 렌더 fps가 목표(세그 ≥ 8Hz, 렌더 ≥ 24fps) 미달이면 이 ADR을 뒤집어 stride 2 서브샘플링부터 시도한다.

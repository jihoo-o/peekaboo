# ADR-0024: 원본 그림을 기기에서 직접 넣는다 (IndexedDB) — 저장소·서버에 올리지 않고 폰에서 바로 원본 사용

- 날짜: 2026-09-17 · 상태: 채택

## 맥락
소유자: "직접 해결해라." 원본 그림은 권리자에게서 받은 파일이고, 이 세션은 그 파일을 갖고 있지 않으며 인터넷에서 가져오는 것은 무단 복제라 하지 않는다. 남은 병목은 "파일을 가진 사람이 git으로 공개 저장소에 올려야 한다"는 절차였고, 그 자체가 라이선스 전에는 부적절하다(공개 Pages에 원본이 노출됨).

## 결정
- 도감 패널에 **원본 그림 넣기** 버튼: 파일 선택(`<id>.png`, `<id>_wave.png`, 여러 개 한 번에)으로 넣으면 IndexedDB(`peekaboo/skins`)에 Blob으로 저장하고 즉시 `skinImages`에 얹는다. 다음 실행부터는 자동 로드. 서버 전송 없음, 저장소 변경 없음.
- 우선순위: 기기 저장 그림 > `manifest.json` 그림 > 캔버스 드로잉. wave만 넣은 종은 무효(본체가 있어야 함).
- 패널에 `원본 그림 n/14 (기기 저장 m파일)` 표시, 잘못된 파일명은 무시하고 개수·예시를 알려준다. **지우기**로 전부 삭제.

## 이유 (공수)
- IndexedDB 래퍼 30줄 + 파일 입력 1개. 폰 갤러리/파일 앱에서 바로 고를 수 있어 git·PC가 필요 없다. 협업 상대에게 받은 파일을 그 자리에서 넣어 시연할 수 있다.
- localStorage는 5MB 한계라 14장(수백 KB씩)에 부족할 수 있어 IndexedDB.

## 결과
- 헤드리스 검증: 더미 `chiikawa.png`·`chiikawa_wave.png`를 파일 입력으로 넣어 `skins=['chiikawa']`, 페이지 재로드 후에도 유지, 도감 썸네일·등장에 반영 확인.
- 브라우저 데이터 삭제 시 함께 지워진다. 여러 기기에 넣으려면 기기마다 넣어야 한다.

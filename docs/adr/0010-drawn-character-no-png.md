# ADR-0010: 캐릭터를 캔버스 드로잉으로, PNG 에셋 없음

- 날짜: 2026-09-15 · 상태: 채택

## 맥락
계획은 "캔버스 드로잉 또는 PNG 1장". 계획의 최소 파일 구성엔 `character.png`가 선택으로 있다.

## 결정
`drawCharacter()`가 원·타원·선으로 몸, 눈(깜빡임), 볼, 입, 팔을 그린다. 이미지 파일을 두지 않는다.

## 이유 (공수)
- PNG는 그리거나 구해야 하고(라이선스 확인 포함), 로드 대기·크기 스케일링·wave 팔 동작을 위한 스프라이트 분리가 따라온다.
- 드로잉은 `size` 하나로 bbox 폭에 맞춰 스케일되고, S5 wave(팔 각도)와 깜빡임을 파라미터로 바로 넣을 수 있다.

## 결과
캐릭터 교체는 `drawCharacter` 한 함수 안에서 끝난다(ADR-0007 참고).

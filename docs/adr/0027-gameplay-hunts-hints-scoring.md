# ADR-0027: 게임 기획 보강 — 코스(여러 마리), 숨긴 사람의 힌트·닉네임·만료·난이도, 핫/콜드, 타이머·점수, 대사 말풍선, 재공유

- 날짜: 2026-09-18 · 상태: 채택 (ADR-0026 위에 얹음)

## 맥락
S21은 "한 마리를 한 곳에 숨기고 링크로 찾기"까지였다. 부실한 부분: 한 번에 한 마리뿐, 찾는 사람에게 줄 문맥(같은 컵이 여러 개일 때)이 없음, 만료 없음, 찾았을 때 보상·기록 없음, 캐릭터가 말이 없음, 링크를 잃으면 재공유 불가, 이미 찾은 링크를 또 열면 아무 안내 없음.

## 결정 (모두 서버 없음, URL·localStorage만)
- **코스(hunt)**: 숨기기 카드에서 "하나 더 숨기기"로 여러 cache를 한 코스에 모으고 "코스 링크 공유"로 `?h=`(caches 배열) 하나로 보낸다. 진행 중 코스는 `draft`로 저장돼 앱을 닫아도 이어진다. 찾는 쪽은 **가장 가까운 미발견 목표**를 자동으로 잡고, 우상단 "목표 n/m" 칩으로 목록을 열어 바꿀 수 있다. 하나를 찾으면 4.5초 뒤 다음 목표로 넘어간다. `?c=` 단일 링크는 1개짜리 코스로 읽는다.
- **숨긴 사람의 손잡이**: 힌트 문구(≤40자, 멀리서는 배너에·근처에선 안내 끝에 표시), 닉네임(≤12자, 링크 제목에 "by"), 만료(1/7/30일, 지나면 목표에서 제외), "20초 뒤 물체 이름 힌트 주지 않기"(난이도).
- **핫/콜드**: 거리 배너 색 — 150 m 밖 파랑, 50~150 m 주황, 50 m 안 빨강. 근처 판정으로 바뀌는 순간 토스트 + 진동.
- **타이머·점수**: 목표를 잡은 시각부터 수집까지 초를 재고, `점수 = 희귀도 기본(흔함 100·보통 200·희귀 400·전설 800) + max(0, 600 − 초)`. 토스트 "찾았다! 우사기 · 1분 23초 · +577점". 누적은 시작 메뉴와 도감 상단에.
- **대사**: 등장 시작과 수집 때 캐릭터 머리 위 말풍선(원작 말버릇 기준 가칭: 하치와레 "なんとかなれ〜！", 우사기 "ウラ！", 모몽가 "なんかちょうだい" 등, 수집 시 "찾았다!").
- **재공유·상태**: 시작 메뉴에 "숨기는 중인 코스(공유/새 코스)", "내가 숨긴 코스" 최근 5개와 다시 공유 버튼, 누적 점수. 다 찾은 코스를 열면 "모두 찾았어요", 이미 찾은 캐릭터를 또 탭하면 "이미 찾은 캐릭터예요".

## 이유 (공수)
- 전부 기존 cache 객체에 필드 몇 개(hint·by·exp·nohint)와 배열 하나(caches)를 더한 것. 링크 길이는 마리당 ~150자라 5마리 코스도 1 KB 안.
- 점수식은 한 줄이지만 "빨리 찾을수록 좋다"와 "희귀할수록 좋다"를 동시에 만든다. 리더보드는 서버가 필요하므로 보류.

## 결과
- 헤드리스(가짜 GPS): 2마리 코스 숨기기(힌트·닉네임·만료·난이도 입력, 하나 더 숨기기 → 재락 → 2개) → 링크에 두 cache 모두 담김. 찾기: 가까운 목표 자동 선택 → 도착 토스트 → 등장(링크의 종) + 말풍선 → 수집 → 점수 토스트·finds·scores → 다음 목표로 전환 → 목록 칩 "목표 1/2".
- 다음 후보: 서버 리더보드, 숨길 때 장면 사진(서버 필요), 찾은 사실을 숨긴 사람에게 알리기(서버 필요).

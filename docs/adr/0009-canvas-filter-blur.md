# ADR-0009: 마스크 페더링을 `ctx.filter = 'blur(2px)'`로

- 날짜: 2026-09-15 · 상태: 채택

## 맥락
S4는 "가장자리 2px 블러"를 요구한다. 선택지는 알파 배열에 박스 블러를 직접 구현하거나, 캔버스 `filter` 속성을 쓰는 것.

## 결정
클리핑 캔버스에 마스크를 `destination-in`으로 그릴 때 `clipCtx.filter = 'blur(2px)'`를 켠다. 직접 구현 없음.

## 이유 (공수)
- 한 줄. 안드로이드 Chrome(주 타깃)은 지원.
- 직접 블러는 루프 하나가 더 늘고(ADR-0006의 픽셀 루프에 추가), 튜닝 대상이 늘어난다.

## 결과
`ctx.filter`를 지원하지 않는 브라우저(구형 Safari)에서는 블러만 생략되고 마스크 클리핑 자체는 동작한다. 오류가 아니다.

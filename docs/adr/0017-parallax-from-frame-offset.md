# ADR-0017: 패럴랙스 — 물체의 화면 내 치우침을 카메라 이동의 근사치로 써서 숨은 캐릭터를 더 드러낸다

- 날짜: 2026-09-16 · 상태: 채택

## 맥락
요청: 캐릭터가 물체 뒤에 숨어 있으니, 옆쪽에서 찍거나 카메라 각도를 바꾸면 더 볼 수 있게. 진짜로 하려면 카메라 포즈(WebXR/ARCore) 또는 자이로+깊이가 필요하다(§0에서 미룬 항목).

## 결정
- **휴식 자세를 반쯤 숨김으로**: 위 배치의 등장 완료 위치를 bbox.y + 0.15h → **0.45h**로 내려 눈 위쪽만 빼꼼 보이게 한다. 옆 배치는 몸의 85% → **55%**만 밖으로.
- **패럴랙스 입력 = 물체 중심의 화면 내 치우침** `(-1~1)`. 카메라가 오른쪽으로 이동하면 가까운 물체는 화면 왼쪽으로 치우친다는 사실을 이용해, 물체가 왼쪽에 있을수록 캐릭터를 물체 기준 **오른쪽**으로(최대 bbox 폭의 55%), 물체가 아래쪽에 있을수록(위에서 내려다봄) **위**로(최대 높이의 35%) 이동한다. EMA(0.12)로 부드럽게.
- 자이로(DeviceOrientation)는 쓰지 않는다.

## 이유 (공수)
- 이미 있는 bbox 값으로 계산되는 두 줄. 권한 요청(iOS의 DeviceOrientation), 회전/이동 분리, 드리프트 처리가 모두 필요 없다.
- 회전만 하는 팬(제자리 회전)에서도 캐릭터가 움직이므로 물리적으로 정확하진 않지만, 사용자가 "옆으로 가서 본다"고 느끼는 동작(몸을 옮기며 물체를 프레임에 두기)에서는 물체가 화면에서 치우치는 방향과 일치한다.

## 결과
- 헤드리스 검증: 물체를 화면 왼쪽으로 가정(px=-1)하면 캐릭터가 bbox 폭의 55%만큼 오른쪽으로(200→334px), 아래쪽(py=1)이면 높이의 35%만큼 위로(384→291px) 이동.
- 실기기에서 반응이 과하거나 약하면 `PARALLAX_X`, `PARALLAX_Y`; 물체를 정확히 중앙에 두면 반쯤 숨은 상태 그대로다.

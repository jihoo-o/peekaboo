# ADR-0016: "짠!" 대신 스을쩍 — 완전히 가려진 위치에서 뒤뚱거리며 걸어 나온다

- 날짜: 2026-09-16 · 상태: 채택 (ADR-0013의 "짠! 등장" 부분을 대체)

## 맥락
요청: 최대한 물체에 가려진 쪽에서 걸어 나오듯, 스을쩍 나타나게. 기존 S8은 easeOutBack 450ms 팝 + 12방향 버스트 + "짠!" 텍스트였고, 위 배치의 시작 위치(bbox.y + 0.6h)는 컵처럼 폭≈높이인 물체에서 캐릭터 윗부분이 처음부터 보였다.

## 결정
- **시작 위치 = 완전히 가려지는 곳**. 위 배치: 하단 중심 y를 `max(bbox.y + 0.6h, bbox.y + 1.2·size)`로 두어 털까지 bbox 상단 아래에 들어가게 한다(물체가 너무 납작하면 bbox 하단 + 0.2·size에서 클램프). 옆 배치: 가장자리에서 안쪽으로 0.7·size.
- **이동 = 2.4초 스니크 곡선** `sneakProgress`: 0→0.3까지 살짝 나왔다가(0.72초), 0.18로 움찔 물러나고(0.36초), 다시 끝까지(1.32초). 나오는 동안 몸을 ±0.07rad로 흔들고(뒤뚱) 위아래로 3.5% 들썩인다(걸음).
- 버스트·"짠!" 텍스트·`drawPop` 삭제. 이미 맞춘 물체(solved)도 같은 스니크로 나오되 5초 충전만 건너뛴다.

## 이유 (공수)
- 곡선 하나(`sneakProgress`)와 기울기 파라미터(`tilt`) 추가로 끝난다. 발 애니메이션이나 스프라이트 시트는 만들지 않는다.
- "가려진 쪽"을 마스크에서 찾는 대신 bbox 기하만 쓴다(ADR-0015와 같은 원칙). 마스크가 bbox보다 작으면(손잡이 옆 빈 공간) 완전히 가려지지 않을 수 있는데, 컵·병·책 같은 통짜 물체에선 문제없다.

## 결과
- 등장 시간이 0.45초 → 2.4초. 너무 느리면 `PEEK_MS`, 움찔의 깊이는 `sneakProgress`의 0.3/0.18.

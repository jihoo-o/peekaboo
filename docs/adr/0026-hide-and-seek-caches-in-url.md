# ADR-0026: 숨바꼭질 포맷 — 특정 장소의 특정 물체에 캐릭터를 숨기고, 링크(URL)에 담아 공유. 서버 없음

- 날짜: 2026-09-18 · 상태: 채택 (S8 "스캔 → 무작위 대상"은 '혼자 놀기' 모드로 남김)

## 맥락
소유자: "포켓몬고처럼 특정 위치의 특정 물체가 고정되어 있게. 누군가 어디에 뭘 숨겨 놓고 다른 사람이 찾을 수 있게." 지금까지는 각 기기가 스캔해서 스스로 대상을 정했다.

## 결정
- **숨기기(hide)**: 아무 물체나 락 확정(연속 3회) → "여기 숨기기" → `cache = { v:1, id, label, sp, at, lat, lng, acc, heading, pitch }`. 캐릭터는 물체 라벨 규칙으로 뽑고 "다른 캐릭터"로 다시 뽑을 수 있다. 숨기기 모드에선 캐릭터가 나오지 않는다(숨기는 사람은 보지 않는다).
- **공유 = URL**: cache를 JSON → base64url로 `?c=...`에 담는다. Web Share API로 보내고, 없으면 클립보드. **서버·계정 없음.** 링크를 가진 사람은 누구나 찾을 수 있다.
- **찾기(seek)**: `?c=`로 열면 메뉴 제목에 "○○가 cup 뒤에 숨어 있어요"가 뜨고, 시작하면 GPS(`watchPosition`)로 숨긴 지점까지 **거리(haversine)·방위(bearing)**를 계산해 상단 배너에 "123 m + 화살표"(나침반 heading 대비 회전)를 보여 준다. `dist > max(25 m, 내 오차 + 숨긴 오차)` 동안은 **멀리** 상태: 물체 락을 막고 이동만 안내한다. 근처에 오면 기존 흐름(물체 발광 → 가장자리 방향 힌트(숨긴 사람의 절대 나침반 방향) → 5초 유지 → 스니크 등장 → 탭 수집). 캐릭터는 링크에 적힌 종으로 고정.
- **GPS 없이 찾기**: 20초 넘게 위치가 안 잡히거나 오차 > 100 m면 배너에 우회 버튼. 실내에서 필수.
- **기록**: 수집 항목에 `cache` id, `finds`(찾은 id)와 `hides`(내가 숨긴 것)를 localStorage에.
- 시작 메뉴 3개: 찾기(링크) / 숨기기 / 혼자 놀기(스캔, 예전 방식). `?mode=hide`로 바로 숨기기.

## 이유 (공수)
- 서버(Supabase 등)를 붙이면 계정·권한·삭제·스팸이 따라온다. URL 한 줄이면 카톡으로 보내는 것으로 "누군가 숨기고 누군가 찾는다"가 성립한다. 링크 길이 ~200자.
- 실내 GPS 오차(10~50 m)는 "근처" 판정에 오차를 더해 흡수하고, 최종 확인은 어차피 **물체 인식**이 한다. 위치는 대략, 물체가 정확.

## 결과
- 헤드리스(가짜 GPS): 숨기기 → 카드에 종·물체·오차·링크. 찾기 → 200 m 떨어진 곳에서 배너 "200 m"·락 차단 → 위치를 옮기면 근처 판정 → 락 → 충전 → 등장(링크의 종) → 수집 → `finds`에 id.
- 같은 물체가 여러 개인 곳(카페 컵)은 구분하지 못한다. 방향(나침반)이 보조. 다음 단계 후보: 숨길 때 사진 한 장을 링크 대신 서버에 올려 "이 장면" 힌트로 보여주기.

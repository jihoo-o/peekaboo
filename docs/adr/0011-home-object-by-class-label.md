# ADR-0011: "최초로 인식된 물체"를 클래스 라벨 하나로 기억 (localStorage)

- 날짜: 2026-09-15 · 상태: **일부 대체됨** → [ADR-0013](0013-scan-then-random-target-and-glow.md). "최초 확정 물체" 대신 스캔 결과에서 무작위 선택. 클래스 라벨 하나로 기억한다는 점은 유지.

## 맥락
요청: "그 공간 안에서 최초로 인식된 물체에 대해서만 캐릭터가 나타나게 하고, 그 값을 기억할 수 있나?" 물체 인스턴스를 정확히 구분하려면 외형 지문(색 히스토그램, 임베딩)이나 공간 앵커가 필요하다.

## 결정
타깃이 확정(연속 매칭 3회)된 첫 물체의 **COCO 클래스 라벨**만 `localStorage['peekaboo.home']`에 저장한다. 이후에는 그 클래스만 락 대상이 된다. 같은 클래스의 다른 개체(다른 컵)는 구분하지 않는다. 초기화는 도감 패널의 버튼 또는 `?reset=1`.

## 이유 (공수)
- 라벨 저장은 3줄. 인스턴스 지문은 조명·각도에 따라 튜닝이 필요하고, 실기기 없이 검증할 수 없다.
- 데모 시나리오(책상 위 컵 1개)에서는 클래스 = 개체다.

## 결과
- 같은 종류의 다른 물체를 비춰도 캐릭터가 나온다. 개체 구분이 필요해지면 bbox 내부 색 히스토그램(코사인 유사도)을 `home`에 추가하는 것이 다음 단계.
- 브라우저별 저장이므로 폰을 바꾸면 기억이 없다.

# ADR-0015: 위 여유가 없으면 옆에서 등장, 한 번 맞춘 물체는 이후 즉시 등장

- 날짜: 2026-09-16 · 상태: 채택

## 맥락
1. 큰 물체(또는 화면 상단에 걸친 물체)는 bbox 위쪽에 캐릭터를 놓을 자리가 없어 HUD에 가리거나 화면 밖으로 나간다.
2. 5초 유지에 성공한 물체는 "정답을 맞춘 것"이므로, 이후엔 인식되자마자 캐릭터가 나와야 한다.

## 결정
- **배치**: 완전 등장 시 캐릭터 윗변(털·말풍선 포함, 폭의 1.35배)이 HUD 아래(120px)보다 위로 올라가면 **옆쪽**으로 바꾼다. 좌우 중 여유가 큰 쪽을 고르고, 여유가 70px 이상일 때만. 옆 배치는 bbox 안쪽(가려짐)에서 가장자리 밖 85%까지 수평으로 나오고, 높이는 bbox 중간(55%)에 둔다. 크기는 화면 폭의 45%와 그쪽 여유 폭으로 제한. 양옆도 없으면 위 배치를 유지하되 HUD 아래로 y를 클램프한다.
- **정답 기억**: 충전(5초)이 끝나 등장하는 순간 `home.solved = true`를 localStorage에 저장. 이후 확정(연속 3회 매칭)되면 charging을 건너뛰고 바로 `peek`(짠!). 힌트 문구("더 가까이", "가만히")도 생략. 초기화하면 함께 지워진다.

## 이유 (공수)
- 자리 판단을 "위 여유 픽셀"과 "좌우 여유 픽셀" 두 숫자로만 한다. 마스크 형태를 분석해 빈 곳을 찾는 방식은 정확하지만 튜닝이 필요하다.
- solved는 불리언 하나. 상태 머신에서 진입 상태만 바꾸면 된다.

## 결과
- 헤드리스 검증: 컵이 화면 상단을 채우는 프레임에서 오른쪽 옆으로 등장하고 화면 안에 들어옴. 첫 등장은 hidden → charging → peek → idle, 락을 끊고 다시 잡으면 hidden → peek → idle(충전 없음). `home.solved: true` 저장 확인.
- 물체가 화면 전체를 덮으면(양옆·위 모두 없음) 캐릭터가 마스크에 완전히 가려질 수 있다. 그 경우는 "더 뒤로 물러나세요" 안내가 다음 후보.

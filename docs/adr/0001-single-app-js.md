# ADR-0001: app.js 한 파일 유지, 모듈 분리 안 함

- 날짜: 2026-09-15 · 상태: 채택

## 맥락
계획은 `index.html` + `app.js` "한 파일, 300줄 내외"였다. S4까지 넣으니 약 490줄이 됐고, `tracker.js`/`character.js`로 나눌지 결정이 필요했다.

## 결정
한 파일로 둔다. 대신 파일 상단 주석과 각 블록의 `// ---- S{n}: ...` 구분자, 코드 내 `// S{n}` 주석으로 단계별 추가 위치를 표시한다.

## 이유 (공수)
- 분리하면 import/export 정리, 단계별 커밋 diff 재구성, Pages 캐시(파일 수 증가) 확인이 추가된다. 데모 단계에서 얻는 건 없다.
- 단계 번호 주석만으로 "어느 단계에서 추가됐는지"라는 원래 요구는 충족된다.

## 결과
S6 이후(three.js 도입)나 §5 로드맵 착수 시 분리한다. 그 전까지는 한 파일.

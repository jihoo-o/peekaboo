# ADR-0003: 카메라를 "카메라 시작" 버튼(사용자 제스처) 뒤에서 시작

- 날짜: 2026-09-15 · 상태: 채택

## 맥락
S1 프롬프트는 페이지 로드 시 바로 `getUserMedia`를 부르는 것처럼 읽히지만, "막혔을 때" 항목에 "`video.play()`가 사용자 제스처 이후인지"가 있다. 모바일 브라우저(특히 iOS Safari)는 제스처 없는 `play()`를 막을 수 있다.

## 결정
초기 화면에 버튼 하나를 두고, 클릭 핸들러 안에서 `getUserMedia` → `play()` → 모델 로드를 순서대로 실행한다.

## 이유 (공수)
- 자동 시작 후 실패 시 "탭해서 재시도" 분기를 만드는 것보다 버튼 한 개가 코드도 짧고 디버깅 경우의 수도 적다.
- 헤드리스 검증에서도 `click('#start')` 한 줄로 동일 경로를 탄다.

## 결과
탭 한 번이 추가된다. 데모 UX엔 무시할 수준.

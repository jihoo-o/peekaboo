# ADR-0023: 협업 조건 — 캐릭터는 재생산이 아니라 원본 에셋을 그대로 쓴다. 캔버스 드로잉은 파일이 없을 때의 대체

- 날짜: 2026-09-17 · 상태: 채택 (ADR-0022의 드로잉을 "대체 수단"으로 격하)

## 맥락
소유자: "여전히 다르다. 협업이라 재생산이 아니라 원본 캐릭터를 그대로 써야 한다." S17의 캔버스 드로잉은 흉내이지 원본이 아니다. 원본은 권리자(스파이럴큐트/대원미디어)가 제공하는 파일이며, 이 세션은 그 파일을 갖고 있지 않고 인터넷에서 가져올 수도 없다(공식 그림 무단 복제이며 프록시도 차단).

## 결정
- **렌더 우선순위**: 원본 에셋(`assets/skins/chiikawa/`) → 없으면 캔버스 드로잉(S17) → `?skin=silhouette`이면 실루엣. 파일이 있는 종은 드로잉 코드를 전혀 타지 않는다.
- **에셋 슬롯 보강**(S18): `manifest.json` 항목을 문자열 또는 `{ id, file, scale, dy, wave }`로 받아 파일명·배율·세로 오프셋·흔들기 그림을 종마다 지정할 수 있게 했다. `<id>_wave.png`가 있으면 탭(wave) 때 자동 교체, 없으면 원본을 회전으로 흔든다. HUD에 `skin n/14`, 누락 파일은 콘솔 경고.
- **검증 방식**: 저장소에 어떤 그림도 넣지 않고, 헤드리스 하네스가 manifest와 더미 PNG(파란 사각형에 "TEST PNG")를 라우팅으로 응답해 등장·흔들기 교체·도감 썸네일·공유 사진까지 원본 경로가 동작하는지 확인했다.
- **인수 절차**: 권리자에게서 14종 PNG(투명, 정면, 하단 정렬)를 받아 폴더에 넣고 manifest에 적는다. 이 작업은 파일을 가진 사람만 할 수 있다.

## 이유 (공수)
- 파이프라인은 이미 있었고(S13), 부족했던 것은 "실제 파일로 검증"과 "그림마다 다른 비율·여백을 흡수할 손잡이"였다. 둘 다 코드 30줄.

## 결과
- 원본 파일이 도착하기 전까지는 드로잉이 보인다. 협업 데모에 드로잉을 내보내면 안 되면 `?skin=silhouette`를 쓰거나 `SPECIES_DRAW`를 비운다.

# ADR-0005: 마스크 극성(물체=0/배경=255)을 bbox IoU로 자동 선택

- 날짜: 2026-09-15 · 상태: 채택

## 맥락
S4 첫 실행에서 마스크가 전부 IoU 게이트(0.2)에 걸렸다. 로그로 확인하니 MagicTouch 카테고리 마스크(`getAsUint8Array`)는 선택한 물체가 **0**, 배경이 **255**였다(픽셀 값 집합 `{0, 255}`, bbox 안은 거의 0). 처음 구현은 `>0`을 전경으로 가정했다.

## 결정
`ingestMask`에서 0-영역과 255-영역 각각의 bbox IoU를 계산해, 더 높은 쪽을 전경으로 쓴다. 그 최대값이 0.2 미만이면 마스크를 버린다.

## 이유 (공수)
- 문서로 극성을 재확인하는 것보다 두 카운트를 한 루프에서 같이 세는 게 빠르고, 버전 업으로 극성이 바뀌어도 코드 수정이 없다.
- IoU 게이트 루프를 이미 돌고 있어 추가 비용이 사실상 0.

## 결과
마스크 채택 후 `mask on | rej 0`, 컵 윗부분이 곡면대로 가려지는 것을 확인. 헷갈리지 않도록 코드 주석에 실측 극성을 남겼다.
